# YouTube Music for Wizard

A music source for Wizard's Music app (like SimpleFIN is for Money). Install it and Music shows YouTube search, radio and songs.

**Needs a home internet connection.** YouTube blocks cloud servers in data centers. It works on a Wizard at home. On a cloud Wizard, install [Wizard Home Relay](https://github.com/humanitylabs-org/wizard-home-relay) on an always-on computer at home that's on your Tailscale and paste its address into this app. The app tests a real download before it says it works.
